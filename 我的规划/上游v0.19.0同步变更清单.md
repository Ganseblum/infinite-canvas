## 上游 v0.19.0 改了什么

共 13 个提交、27 个文件（+424 / −132），集中在画布前端与插件目录，未触及服务端。

### 1. 画布图片 WebP 本地缩略图预览（未合入）

提交：`ed7e901`、`48637e5`、`52d85d6`。上游为解决图片多时反复解码原图卡顿：

- 画布图片节点、左侧元素列表、节点参考栏、素材卡片、素材选择器、生图历史缩略图、图片/视频工作台参考条，一律改渲染**长边 768px 的 WebP 预览**。
- 预览只在本地 IndexedDB（`image_previews` store），不写进画布/素材数据、不参与导出与 WebDAV 同步；图片删除或不再引用时预览同步清理。
- 打开大图、编辑、下载、导出、生成参考仍用原图；本身 ≤768px、纯远程 URL、自定义封面的图直接回退原图。
- 渲染时按 `pickImageSource` 依「屏幕实际需要像素 × 缩放 × devicePixelRatio」动态决定用预览还是原图（放大后自动换原图避免发虚）。

**我方处理：未合入。** 上游实现挂在我方已删除的本地图片存储（`image-storage.ts` / `use-asset-store.ts`，画布与素材已改服务端权威）。硬合会产生引用不存在模块的代码。已列入 todo：移植思路是图片经 `media-ingest` 上传完成后从服务端拉原件生成预览，渲染侧 `pickImageSource` 与 `lib/image-thumbnail.ts`（及其测试）可直接复用（上游提交 `ed7e901` / `48637e5` / `52d85d6`）。

### 2. 画布拖拽与连线渲染性能（已合入）

提交：`f64b58c`（来自上游 fork PR `peanut2001/perf/canvas-drag-render`）：

- 拖拽节点时，位置更新与投放目标组检测**合并到同一个 requestAnimationFrame 提交**，mousemove 高频触发不再逐次重渲染；拖拽数据结构从数组扫描改为 **Map/Set 的 O(1) 查找**（`initialSelectedNodes: Map`、`movedIds: Set`）。
- 连线按**视口裁剪**渲染：缩放/平移只看局部时，穿越视口的连线照常渲染（含两端都在屏幕外的），连线点选、右键菜单、新建连线虚线预览不受影响。
- 组交互语义保持：拖节点到组上方高亮、松手入组、拖出移组，拖组节点自身不触发高亮。

**我方处理：全部合入。** 我方此前已有自己的 rAF 合批实现（数组版），本次统一到上游 Map 版；连线裁剪取上游版。

### 3. 图片/文本上层操作按钮改为悬停显示（已合入）

提交：`ca0f09f`。画布图片与文本节点上层的「下载」「设为主文本」按钮组改为鼠标移入节点才显示（`group/node` + `pointer-events-none` / `group-hover/node:` 纯 CSS），移出隐藏，不再遮挡画面内容。仅改 `canvas-node.tsx` 四处样式。

**我方处理：合入**（该提交与我方改动无冲突区域，是手工补回的四处 className）。

### 4. 生图请求 10 分钟超时（不适用）

提交：`f84f3ff`。上游给浏览器直连的生图/图片编辑/Gemini 生图请求加 10 分钟超时，避免接口长时间不返回时一直停在生成中。

**我方处理：不适用、未合入。** 我方 AI 请求已全部走服务端转发，超时由 `AI_IMAGE_TIMEOUT`（默认 180s）等服务端配置控制，浏览器直连代码已删。

### 5. ZCode 插件支持（已合入）

提交：`0df050c`、`4345b50`、`920a2ad`（来自上游 fork PR `moyu12-ae/feat/zcode-infinite-canvas-plugin`）。`plugins/infinite-canvas/` 下新增 `.zcode-plugin/plugin.json`（插件清单，v0.1.0）与 `marketplace.json`，更新 `.codex-plugin/plugin.json` 与 README——让 ZCode / Codex 这类编码 Agent 通过本地 Canvas Agent MCP 服务读写、操作画布。

**我方处理：目录随上游整体合入，无冲突。** 我方画布 Agent 协议有自己的消息归属与版本规则，该插件目录属上游侧发布件，后续是否启用/改造另行决策。

### 6. 发布收尾（已合入）

提交：`e856c87`：上游 `VERSION` 升到 `v0.19.0` 并写 CHANGELOG。我方 `CHANGELOG` 按手册取并集（我方 Unreleased 在前，上游 v0.19.0 版本块并入版本序列）。
