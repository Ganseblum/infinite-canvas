核心功能

无限画布是一个基于浏览器的 AI 创作工作台，以下是其核心能力概览。

无限画布

在一块可无限平移与缩放的画布上自由排布图片、视频、文本与音频节点，通过连线组织生成流程。

多模型生成

支持接入任意 OpenAI 兼容接口，图像、视频、文本、音频四类任务可并行执行。

提示：生成失败会自动返还积分，可在生成记录中一键重试。

Agent 助手

侧边 Agent 面板可通过自然语言直接操作画布：创建节点、修改参数、发起生成。
