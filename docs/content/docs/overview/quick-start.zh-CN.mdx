# 快速开始

全站功能登录后使用，画布、素材、生成记录与媒体都由服务端保存。

## Docker 启动

```bash
git clone git@github.com:basketikun/infinite-canvas.git
cd infinite-canvas
cp .env.example .env
docker compose up -d
```

启动后访问：

```text
http://localhost:3000
```

`.env` 中必须填写数据库、`JWT_SECRET`、`CREDENTIAL_MASTER_KEY`、管理员账号与邮件配置；完整变量说明见仓库根目录 `.env.example`。

## 本地启动

```bash
git clone git@github.com:basketikun/infinite-canvas.git
cd infinite-canvas
cp .env.example .env
docker compose up -d db
cd server && go run ./cmd/server
cd web && bun install && bun run dev
```

## 首次使用建议

- 使用 `.env` 里配置的管理员邮箱与密码登录。
- 服务端启动时会自动建表，并写入 `free` / `paid` / `sunset` 三档默认档位。

## 说明

- 创建账号需要完成邮箱验证，验证邮件由 `MAIL_DRIVER` 指定的方式发出；本地开发可用 `log` 驱动，邮件内容直接打到后端日志。
- 生产部署请使用仓库根目录的 `deploy.sh` 与 `deploy/env.prod`，不要直接部署规划分支。
