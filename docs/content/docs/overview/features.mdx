# Features

## Canvas projects

- Create, rename, duplicate, delete, import, and export canvas projects.
- Persist projects on the server; every signed-in device picks up where you left off, with autosave and conflict prompts.
- Keep viewport, background, nodes, connections, and assistant sessions with each project.

## Infinite canvas

- Pan, zoom, reset the view, select multiple nodes, copy and paste, undo and redo.
- Drag files onto the canvas and use lines, dots, or a blank background.
- Export the entire canvas or selected elements with their resources.

## Nodes and workflows

- Text, image, video, and generation-configuration nodes.
- Connect text prompts and reference media to generation nodes.
- Generate or rewrite text, create images, edit images from references, and create videos.
- Preserve original image ratios by default and organize batch results as connected nodes.
- Record prompts, models, dimensions, quality, and references on generated nodes for retries.

## AI generation

Generation is routed through the server: the browser only talks to `/api/ai/*`, models come from the server catalog, channel keys are encrypted server-side, and no credentials exist in the browser.

- Quote first so the cost and any active discount are known before generating; insufficient credits are rejected before the upstream call.
- Credits spend the granted bucket before the purchased one and refund to the original bucket on failure; an idempotency key deduplicates retries.
- Video runs as an async task polled by the server, so closing the page still lets it finish, and failures refund automatically.
- Chat uses a single event stream with incremental output; stopping also cancels the upstream request.
- Generated results are stored server-side and served from `/api/media/...` instead of expiring third-party URLs.
- In-site generation and uploads are moderated: prompts and references are checked before credits are reserved, artifacts and uploads pass through a quarantine area before normal storage, rejected inputs cost nothing, rejected artifacts are not refunded, and false rejections can be reviewed and compensated by admins.

## Canvas Agent

- Connect local Codex through Canvas Agent and MCP without giving a web server direct access to browser state.
- Read the active canvas, selection, nodes, edges, generation status, and apply structured operations.
- Use Codex from the browser side panel with streaming responses, history, approvals, permissions, diagnostics, and local Skills.
- Isolate active canvases and turns across multiple browser tabs.

See [Codex App Plugin](/docs/overview/codex-app-plugin) for installation and usage.

## Plugin system

Canvas plugins can contribute node types, rendering, inspectors, serialization, migration, toolbar actions, and optional AI generation capabilities. Built-in and local plugins are managed through the canvas UI.

## Prompts and assets

- Use seven built-in prompt sources from the [Image Prompts](https://github.com/yukkcat/image-prompts) registry, with independent enablement, manual refresh, and scheduled refresh.
- Add, edit, and remove custom standard JSON sources while retaining the last successful cache when refresh fails.
- Search across enabled sources, filter by tags, inspect prompt details, copy prompts, and insert them into the canvas.
- Store reusable images, videos, audio, and prompt assets in the browser.

See [Third-party Prompt Sources](/docs/overview/third-party-prompt-repositories) for the complete built-in list.

## Accounts and credits

- Everything requires signing in. Registration sends a verification email, and password reset, the profile page, and account deletion (7-day cooling period with undo) are available.
- Credits are split into purchased and granted buckets. Generations spend granted first and refund to the original bucket on failure; granted credits never make an account paid.
- Top-ups are packaged orders paid with Alipay or WeChat; credits land in the same transaction as the order state change, and repeated callbacks never credit twice.
- The profile page shows the current plan, both buckets, recent transactions, and storage usage; media expiring within two days is surfaced on the profile and canvas list pages.

## Configuration and administration

- Export and import channel, model, generation, and prompt-source settings.
- The platform model catalog, promotions, and price matrix are served by the API; the models page, pricing page, and admin pages read from it.
- Manage users, the model catalog, promotions, packages, and orders from `/admin`; non-admins are redirected and rejected by the API.

## Current limitations

- Canvases, assets, generations, and media live on the server; AI requests are routed through the backend and the browser holds no channel credentials.
- Production Docker static-resource paths still require broader deployment verification.
