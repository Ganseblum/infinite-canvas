# Quick Start

Everything requires signing in. Canvases, assets, generations, and media are stored by the server.

## Run with Docker

```bash
git clone git@github.com:basketikun/infinite-canvas.git
cd infinite-canvas
cp .env.example .env
docker compose up -d
```

Open `http://localhost:3000`.

Fill in the database, `JWT_SECRET`, `CREDENTIAL_MASTER_KEY`, admin account, and mail settings in `.env`; the full list is documented in `.env.example`.

## Run locally

```bash
git clone git@github.com:basketikun/infinite-canvas.git
cd infinite-canvas
cp .env.example .env
docker compose up -d db
cd server && go run ./cmd/server
cd web && bun install && bun run dev
```

## First-time setup

- Sign in with the admin email and password from `.env`.
- The server creates tables on startup and seeds the default `free` / `paid` / `sunset` plans.

## Notes

- Registration requires email verification. Local development can use `MAIL_DRIVER=log` to print emails to the backend log.
- For production, use `deploy.sh` with `deploy/env.prod`; do not deploy the planning branch directly.
