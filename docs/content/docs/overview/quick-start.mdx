# 快速开始

全站功能登录后使用，画布、素材、生成记录与媒体都由服务端保存。

## Docker 启动

```bash
git clone git@github.com:basketikun/infinite-canvas.git
cd infinite-canvas
cp .env.example .env
docker compose up -d --build
```

首次启动会本地构建 app / admin / api 镜像（不使用上游发布镜像），构建完成后访问：

```text
http://localhost:3000
```

`.env` 中必须填写以下内容，否则 api 会拒绝启动、整栈起不来：

- 数据库密码与 `DATABASE_URL`（全栈部署 host 保持 `db`），`MYSQL_*` 仅在数据卷首次初始化时生效。
- `JWT_SECRET`（至少 32 字符）与 `CREDENTIAL_MASTER_KEY`（正好 32 字节）。
- `ADMIN_EMAIL` / `ADMIN_PASSWORD` 管理员账号。
- `FREE_GRANT_ENABLED=true` 时 `FREE_GRANT_CAMPAIGN_ID`、`FREE_GRANT_DAILY_BUDGET_MICROS`、`FREE_GRANT_RISK_THRESHOLD` 必填且大于 0；不需要免费额度就直接设 `FREE_GRANT_ENABLED=false`。
- 本地无 SMTP 时把 `MAIL_DRIVER` 设为 `log`，验证邮件内容会打进 api 容器日志。

完整变量说明见仓库根目录 `.env.example`。

## 本地启动

```bash
git clone git@github.com:basketikun/infinite-canvas.git
cd infinite-canvas
cp .env.example .env
docker compose -f docker-compose.local.yml up -d db
cd server && go run ./cmd/server
cd web && bun install && bun run dev
```

数据库端口映射在 `docker-compose.local.yml` 里（`127.0.0.1:13306`）；本机 `go run` 时把 `.env` 里 `DATABASE_URL` 的 host 从 `db:3306` 改成 `127.0.0.1:13306`。Go 服务启动时会自动加载 `.env`（已导出的环境变量优先），不需要手动 `export`。

## 首次使用建议

- 使用 `.env` 里配置的管理员邮箱与密码登录。
- 服务端启动时会自动建表，并写入 `free` / `paid` / `sunset` 三档默认档位。

## 说明

- 创建账号需要完成邮箱验证，验证邮件由 `MAIL_DRIVER` 指定的方式发出；本地开发可用 `log` 驱动，邮件内容直接打到后端日志。
- 生产部署请使用仓库根目录的 `deploy.sh` 与 `deploy/env.prod`，不要直接部署规划分支。
