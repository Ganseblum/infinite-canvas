## 经验教训（已复现两次，已沉淀进 AGENTS.md）

- **SQLite 单测覆盖不到 MySQL 特有错误**：字符串列长度、保留字列名两次在真库才炸。涉及新表或新列名时，必须在一台真实 MySQL 上跑一次迁移。
- **环境变量的 fail-fast 不等于模板真的读了它**：admin 入口脚本检查过 `API_BASE_URL` 但 `index.html` 漏加载 `/config.js`，变量检查通过而应用仍打错地址。新增运行期变量要沿「注入 → 加载 → 使用」全链路核对。
