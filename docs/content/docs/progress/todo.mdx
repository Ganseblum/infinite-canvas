## 经验教训（已复现两次，建议写进 AGENTS.md）

- **SQLite 单测覆盖不到 MySQL 特有错误。** 已发生两次：字符串列被建成 longtext 导致建唯一索引失败；以及用 MySQL 保留字 `key` 作列名导致 `Where("key = ?")` 语法错误、api 反复重启。两次都是 11 个测试包全绿而真库上炸。建议：涉及新表或新列名时，必须在一台真实 MySQL 上跑一次迁移。
- **环境变量的 fail-fast 不等于模板真的读了它。** admin 容器入口脚本检查了 `API_BASE_URL` 非空，但 `index.html` 漏了加载 `/config.js`，于是变量检查通过而应用仍打错地址（表现为 POST 返回 405）。
