# 设计稿与接口对照

本文档把 `design/html/` 下的前端设计稿逐页对照仓库根目录 `我的规划/账号后端总规划.md`（及第一期至第五期分册）中已定义的接口，标注每页的接口覆盖状态，并列出需要补规划或改设计稿的缺口。后端尚未开工，当前仓库只有浏览器直连上游的 `canvas-proxy` 与本地 Agent 服务，下表中的「已覆盖」均指**已在总规划中定义**，不是已实现。

## 冲突项：设计稿与规划矛盾，需改设计稿

以下三项已于 2026-09 在设计稿中修正：

1. **`config.html` 配置页**。原设计包含「接口地址 + API Key + 测试连接」，与规划第四期移除用户自定义渠道冲突。已改为纯偏好设置（主题、语言、通知、本地缓存管理），渠道与密钥配置整块删除。
2. **`pricing.html` 与 `account.html` 的订阅模型**。已从「专业版/团队版 月付/年付」改为「点数充值档位（体验/标准/大额包）+ 免费与付费权益对照」，付费身份由充值自动获得并带有效期，对齐双桶点数模型；个人中心改为「点数与用量」（双桶余额 + 充值入口）。
3. **`admin-billing.html` 的退款操作**。规划明确「订单不支持退款」。已移除退款按钮与筛选，改为「管理员补偿积分」弹窗（进 `granted` 赠送桶、强制填写说明、标注不产生付费身份）。

## 内容审核（NSFW）呈现

第五期已完整规划内容审核（开源方案：图片 NSFWJS、文本 Detoxify，视频抽帧复用 NSFWJS，覆盖 prompt / reference / artifact / upload 四阶段），设计稿已补齐对应状态：

- 两个工作台：生成按钮上方提示「输入被拒不扣点；产物审核不通过仍会扣点」；Mock 流程含「内容未通过安全审核」拒绝态（区分于普通失败，无重试、提供「修改内容」入口）。
- `assets.html`：上传区标注入盘审核，未通过不占用配额。
- `admin-content.html` 新增「内容安全审核」页签：审核统计（审核量、命中率、待复核、误判改判率）、审核记录表（四阶段、命中标签、服务商摘要）、复核详情弹窗（隔离原件 5 分钟预览、改判通过/拒绝、补偿积分二次确认进入赠送桶）。

## 缺失项：设计稿有、规划无接口

按影响面排序：

1. **社区整套接口**（`community.html`、`admin-content.html` 审核页）：作品发布、分页浏览、点赞、复刻计数、举报与下架、用户主页。规划完全没有社区域，需要新增一组 `/api/community/*` 与对应管理接口，并决定社区内容是否复用 `media_files` 存储。
2. **运营活动接口**（`activity.html`、`admin-content.html` 活动页）：规划只有「模型折扣活动」（`/api/admin/model-promotions`），不覆盖设计稿中的创作比赛、每日签到、邀请返利。签到与邀请返利涉及防刷风控（对齐第一期的注册限流思路），工作量需单独评估。
3. **系统设置接口**（`admin-system.html`）：站点公告、开放注册开关、维护模式、生成限制（超时/重试/并发/上传上限/免费额度）。规划的管理接口没有这一组；生成限制中的数值属于会改变线上行为的边界值，落库前需按项目约定逐项确认默认值。
4. **管理员账号管理**（`admin-system.html`）：管理员列表、邀请、改权限、移除。规划只有 `role = admin` 中间件，没有管理员自身的增删改接口。
5. **文档管理 CMS**（`admin-docs-mgr.html`）：文档树、Markdown 编辑、发布、版本历史与回滚。规划未包含，可考虑直接复用现有 Fumadocs 静态文档 + Git 流程，砍掉在线 CMS 以减少范围。
6. **第三方登录**（`login.html` / `register.html` 的 GitHub / Google 按钮）：规划认证只有邮箱密码 + 邮件验证，没有 OAuth。要么补规划，要么设计稿先移除。
7. **两步验证与登录设备管理**（`account.html` 安全设置）：规划有密码修改与注销，没有 2FA 与设备会话管理。
8. **邮箱验证码登录**（`login.html` 的验证码 tab）：规划只有密码登录 + 忘记密码重置，没有「验证码直接登录」形态。
9. **后台总览的收入与转化率指标**（`admin.html`）：`/api/admin/stats` 只定义了用户数、存储总量、当日生成量，收入/转化率需要扩展或明确不做。

## 已覆盖项（无需改动）

- 认证与账号：注册、登录、双令牌、邮件验证、忘记/重置密码、资料修改、改密、注销与冷静期 → `login.html`、`register.html`、`account.html` 主体。
- 资源域：画布 CRUD（乐观锁）、素材 CRUD、生成记录游标分页、媒体上传与直读 URL → `assets.html`、`account.html` 我的作品、两个工作台的记录面板。
- AI 转发：报价预扣（`/api/ai/quote`）、图片/视频/音频/对话、视频任务轮询、失败退点 → 两个工作台的 Mock 流程与规划状态机一致（pending → success/failed，失败返还）。
- 模型目录与渠道：`/api/models` 含约束与价格矩阵；`/api/admin/models`、`/api/admin/channels`（Key 只写不读）→ `models.html`、`admin-models.html`。
- 点数与订单：双桶余额、流水游标分页、充值档位、下单、回调验签幂等、订单列表 → `account.html` 用量页、`admin-billing.html` 主体。
- 内容审核：内联审核 + 人工复核三接口 → `admin-content.html` 审核页可对齐（仅社区部分超出范围）。
