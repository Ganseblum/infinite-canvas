# Local Development

The project is split between `web/` (frontend) and `server/` (Go backend). Canvases, assets, generations, and media are stored by the server.

## 1. Database and backend

```bash
cp .env.example .env   # fill DATABASE_URL, JWT_SECRET, CREDENTIAL_MASTER_KEY, ADMIN_EMAIL, ADMIN_PASSWORD, MAIL_DRIVER at minimum
docker compose up -d db
cd server
go run ./cmd/server
```

The API listens on `http://localhost:8080`, creates tables on startup, and seeds the default plans and admin account.

## 2. Frontend

```bash
cd web
bun install
bun run dev
```

Open `http://localhost:3000` and sign in with the admin account from `.env`.

## 3. Documentation site

```bash
cd docs
bun run dev
```

Common locations:

- Canvas, pages, and interactions: `web/`
- Accounts, resources, media, and billing APIs: `server/internal/`
- Prompt caching: `web/src/services/api/prompts.ts`
- Documentation content: `docs/content/docs/`
