# 本地开发

主要目录是 `web/`（前端）与 `server/`（Go 后端），画布、素材、生成记录与媒体都由服务端保存。

## 1. 准备数据库与后端

```bash
cp .env.example .env   # 至少填写 DATABASE_URL、JWT_SECRET、CREDENTIAL_MASTER_KEY、ADMIN_EMAIL、ADMIN_PASSWORD、MAIL_DRIVER
docker compose up -d db
cd server
go run ./cmd/server
```

后端默认监听 `http://localhost:8080`，启动时会自动建表并写入默认档位与管理员。

## 2. 启动前端

```bash
cd web
bun install
bun run dev
```

前端默认访问 `http://localhost:3000`，使用 `.env` 中配置的管理员账号登录。

## 3. 启动文档站

如果需要单独调整文档站，在 `docs` 目录执行：

```bash
bun run dev
```

## 常见场景

- 改画布、页面和交互：主要看 `web/`
- 改账号、资源、媒体与计费接口：主要看 `server/internal/`
- 改提示词缓存：主要看 `web/src/services/api/prompts.ts`
- 改文档站内容：主要看 `docs/content/docs/`
